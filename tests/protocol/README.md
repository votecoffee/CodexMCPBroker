# Released Tasks schema fixture

`tasks-2026-07-28.schema.json` is an unmodified copy of the released [MCP Tasks JSON Schema](https://github.com/modelcontextprotocol/ext-tasks/blob/main/schema/2026-07-28/schema.json). It checks actual extension responses independently of the framework's models. SHA-256: `bf30afb7ac251e3e22c037b7a685f60ef6603031b5484c0d08b1fa0bbe86d460`.

The upstream Apache 2.0 license is preserved in `LICENSE.ext-tasks`. The framework's own source remains MIT licensed. Tests use this local snapshot and make no network requests. Updating it requires an explicit protocol-version review; do not replace it with the upstream draft schema. Passing selected wire validations is not a claim of implementing every optional extension feature.
